# 2026-11-01

## M2 第 2 步完成：可观测（日志/错误面板）

### 新增
- **`packages/gateway/src/logs.ts`**：`LogStore`（按 appId 隔离、1s 内同句合并 `repeat++` 且 id 不变、
  上限截断）、`stripAnsi`、`classifyLine`（stderr / error / warn / fail → 级别）、`parseClientLog`（页面上报的 zod 校验）
- **`proxy.ts`**：`POST /__tenon/log` 在路由分发之前拦下交给 `onClientLog`，回 204，不转发上游
- **`spawnLogged` 加 `onLine` 钩子**：vite / api（含 tsc 编译报错）每行都进 LogStore
- **协议**：`LogEntry/LogSource/LogLevel`、`app.log` SSE 事件、`logs.list` / `logs.clear` RPC
- **前端**：`useWorkspace` 的 logs 状态（按 id upsert、上限 300、切应用清空、logs.list 首拉）+
  `features/logs/LogPanel.tsx`（折叠底栏、来源筛选、错误高亮、详情展开、清空），挂在 PreviewPanel 下
- **两个模板**：`src/tenon-log.ts`（onerror / unhandledrejection → 同源 POST，keepalive，零依赖）+
  `src/tenon-boundary.tsx`（ErrorBoundary，报完再渲染降级 UI），main.tsx 换成 Boundary 包 App

### 设计要点
- 日志跟应用走不跟预览跑：停预览缓冲还在，`app.delete` 才 `forget()`
- 合并后的条目照样推（id 不变 → 前端 upsert → 一条 ×N，不跳行）
- 页面上报不带任何凭证（同源相对路径就够，铁律 2 方向）
